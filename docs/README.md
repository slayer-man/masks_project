# Проект "Домашняя работа"

## Описание:

Проект "Домашняя работа" - это функционал, который принимает на входе от пользователя номер карты и счета и выводит его маску, так же выводит тип карты или счета и маску, меняет формат введенный пользователем даты, фильтрует списки со словарями и сортирует словари по убыванию даты.

## Установка:

1. Клонируйте репозиторий:
```
git clone git@github.com:slayer-man/masks_project.git
```
2. Установите зависимости:
```
pip install -r requirements.txt
```
3. Инициализируйте виртуальное окружение** командой:
```
python -m venv <название_окружения>
```
*Например:*
```
python -m venv venv
```
*   на macOS и Linux:
```
source .venv/bin/activate
```
*   на Windows:
```
.venv\Scripts\activate
```
