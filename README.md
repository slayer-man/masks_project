## Описание:

Проект "Домашняя работа" - это функционал, 
который принимает на входе от пользователя номер карты и счета и выводит его маску, 
так же выводит тип карты или счета и маску, меняет формат введенный пользователем даты, 
фильтрует списки со словарями и сортирует словари по убыванию даты. Добавлен модуль 
generators.py, в нем используется код генератор банковских карт card_number_generator, 
который может сгенерировать номера карт в заданном диапазоне от 0000 0000 0000 0001 
до 9999 9999 9999 9999, генератор для работы с массивами транзакций: Функция 
filter_by_currency, которая принимает на вход список словарей, представляющих транзакции,
функция  возвращает итератор, который поочередно выдает транзакции, где можно задать 
валюту согласно стандарту ISO 4217. Есть генератор transaction_descriptions, который 
принимает список словарей с транзакциями и возвращает описание каждой операции по очереди.  
Реализован модуль decorators.py. Декоратор log принимает необязательный аргумент 
'filename', который определяет имя файла, в который будут записываться логи.
Если 'filename' не задан, то логи выводятся в консоль. Если вызов функции закончился ошибкой, 
записывается сообщение об ошибке и входные параметры функции.
Также есть модули для тестирования кода.

Реализована функция, которая принимает на вход путь до JSON-файла и возвращает список 
словарей с данными о финансовых транзакциях. Если файл пустой, содержит не список или не найден, 
функция возвращает пустой список. Функция находится в модуле utils.py

Файл с данными о финансовых транзациях operations.json находится в директории data/ в корне проекта.

Реализована функция, которая принимает на вход транзакцию и возвращает сумму транзакции (amount) в рублях, 
тип данных — float. Если транзакция была в USD или EUR, происходит обращение к внешнему API для получения 
текущего курса валют и конвертации суммы операции в рубли. Для конвертации валюты используется Exchange 
Rates Data API: https://apilayer.com/exchangerates_data-api.

Модуль exchange_rate.py обращается ко внешнему API, считывет информацию о курсах заданных валют (USD, EUR) и
сохраняет их в фаил exchange_rates.json, на случай отсутствия интернета или превышения количества запросов 
ко внешнему API. Также в нем написаны функции для вывода ошибок, если чтение к диску запрещено или отсутствует
ключ к внешнему API. При запуске кода проверяется возможность считать данные из сети, если нет, то обращение 
идет к файлу exchange_rates.json, если его нет или он пуст, то выдет ошибку.
* **Отказоустойчивость сети (Fallback)**: В случае падения интернета, блокировки запросов или исчерпания лимитов API (`Read timed out`), приложение автоматически переключается на чтение локального файла-кэша `data/exchange_rates.json`. Работа пользователя не прерывается.
* **Логирование**: Все критические события, статусы HTTP-ответов сервера (например, 200, 401, 429) и отладочная информация пишутся в фоновом режиме в файлы папки `logs/` в кодировке `UTF-8`.

## Запуск функции конвертации валют в рубли
## Запуск производится из корня проекта командой:
1. Для Windows
```commandline
python main.py
```
2. Для MacOS и Linux
```commandline
python3 main.py
```

## Установка:

1. Клонируйте репозиторий:
```
git clone git@github.com:slayer-man/masks_project.git
```
2. Установите зависимости:
```
pip install -r requirements.txt
```
3. Инициализируйте виртуальное окружение** командой:
```
python -m venv <название_окружения>
```
*Например:*
```
python -m venv venv
```
*   на macOS и Linux:
```
source .venv/bin/activate
```
*   на Windows:
```
.venv\Scripts\activate
```
